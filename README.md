# Clinique Aimé++

A modern, responsive website for a dental clinic in Yattaya, Conakry, Guinea.

## Features

- Clean, professional design with white and black color scheme
- Fully responsive layout that works on all devices
- Mobile-first navigation with hamburger menu
- Smooth scrolling animations and effects
- Video hero section on homepage
- Contact form for appointment requests
- Localized content for Guinea

## Pages

1. **Home** - Main landing page with clinic information
2. **Services** - Detailed list of dental services offered
3. **Contact** - Contact information and appointment request form

## Technical Details

- Pure HTML, CSS, and JavaScript (no frameworks)
- Responsive design using CSS Grid and Flexbox
- Optimized for performance and accessibility
- SEO-friendly with proper meta tags and sitemap

## Deployment

To deploy this website:

1. Upload all files to your web server
2. Ensure the img folder and all its contents are uploaded
3. Verify all links are working correctly
